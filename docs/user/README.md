# OpenPlush for makers

OpenPlush turns a 3D model of a plush into a sewing pattern you print, cut and sew. You give it a model, decide where the seams go, and it works out the flat pattern pieces, adds the seam allowance, and lays the pieces out on paper so they print at true size. It is free, and everything happens on your own computer.

This guide is for you if you sew plush and want to use OpenPlush to make your own patterns. You do not need to know how the tool is built, and nothing here asks you to type commands or read code. If you want to change OpenPlush itself, the contributor guide is the place for that.

## What is here

The guide describes what OpenPlush can do today and grows as the tool does. Every step of making a pattern gets its own page when that step is ready to use, and every message the tool can show you gets an explanation of what happened and what to do next.
