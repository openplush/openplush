# Crates

What each engine crate contains **today**, and what it actually depends on. Which crate *should* own a new piece of code is a rule, kept in [`crates/AGENTS.md`](../../crates/AGENTS.md#where-code-goes); the allowed dependency graph is in the [plan](../../specs/001-pattern-pipeline/plan.md#crate-dependency-dag-enforced) and enforced by `scripts/check-boundary.sh`. Signatures and item docs: `cargo doc --workspace --no-deps --open`.

| `openplush-io` | `Format` (OBJ, glTF, GLB, STL, PLY); `IoError` (`Parse`, `NonFiniteInput`, `Mesh`); `obj::read(bytes)`, OBJ to `TriangleSoup`. The OBJ reader reads `v`, `vt` (`v` defaults to 0) and `f` in all four corner forms, with negative indices counting back from the line and positive ones checked against the whole file. Every `v` line becomes a soup vertex in file order, used or not, and only its first three numbers are read. A corner's provenance is its primitive and its 0-based position index. A primitive is a maximal run of `f` lines with no `o`, `g` or `usemtl` between them, numbered from 0, so one material each. The soup's `SourceMaterials` holds the `usemtl` names exactly as written (trailing blanks kept, a comment ends the name), each once in first-use order, including a name no face uses; a `\`-continued name keeps any blanks before the backslash and gains one space at the join; a primitive's material is the last `usemtl` before its faces, kept across `o` and `g`, or none if no `usemtl` came first. No MTL file is read, and `extra_uv_sets` is 0. A `v` line takes the primitive current where it appears. Corner UVs are present only if some face gives one. A leading byte-order mark is skipped, `#` comments are stripped and `\`-continued lines joined. Normals, smoothing, lines and points are skipped; free-form geometry (`cstype`, `curv`, `curv2`, `surf`) is refused, since skipping it would lose surface. Non-UTF-8 text (anywhere, comments included) and more than 2^32 − 1 vertices are refused as `Parse`; so is any statement that cannot be read, with a detail starting `line N:`: a non-number, a vertex with under three coordinates, a non-finite UV, a `usemtl` with no name, a face with under three corners, an index of 0 or out of range, and a polygon that crosses itself. `NonFiniteInput` lists every NaN or infinite vertex, used or not, in file order. Triangulation never moves or adds a vertex: a quad splits on its shorter diagonal unless that diagonal lies outside; a larger polygon is ear-clipped on the plane its Newell normal faces, with exact predicates, and a corner that coincides with an ear's corner does not block it, so a hole joined by a doubled bridge edge clips. A polygon with no split whose triangles all turn its way is refused, unless its corners are collinear: then it is split and validation reports the zero-area triangles. Ear-clipping is quadratic in the polygon's corner count, so an OBJ face of more than 1000 corners is `Parse` (`line N:`). `stl::read(bytes)`, STL to `TriangleSoup`: a file is binary when its length is exactly `84 + 50 * n` for the `n` its header declares, otherwise ASCII text starting with `solid` (after blanks and a byte-order mark). Each triangle gives three soup vertices in file order, joined by the weld; a corner's provenance is primitive 0 for binary and the solid's 0-based index for ASCII, with its vertex position; no UVs, and one material-less primitive per solid. Facet normals and attribute bytes are not read. `Parse` details for ASCII start `line N:`; a file that is neither form names its length and the length its header declares; `NonFiniteInput` names every NaN or infinite vertex; more than `u32` vertices is `Parse`. `ply::read(bytes)`, PLY to `TriangleSoup`, ASCII or binary little or big endian. List count and item types must be integers, and an ASCII integer must fit its declared type; an ASCII `float` is rounded to 32 bits as a binary one is. A corner's provenance is primitive 0 and its vertex position; other properties and elements are read past. `Parse` details start `line N:` or `byte N:` where the reader can say where; `NonFiniteInput` names every NaN or infinite vertex. | `openplush-geom`, `openplush-mesh`, `thiserror` |
