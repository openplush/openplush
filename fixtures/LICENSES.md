# Fixture licenses

Only CC0 and CC-BY models may ship here. Every fixture file has an entry: either its own, or its directory's when every file in it shares one.

| Path | License | Source |
|---|---|---|
| `fabrics/` | CC0-1.0 | Written by hand by the OpenPlush project |
| `meshes/capsule.obj` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/cube.obj` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/sphere.obj` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/faceted.glb` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/quadruped.glb` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/near-symmetric.glb` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/asymmetric.glb` | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `defects/` (every file) | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `meshes/source-seams/` (every file) | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |
| `seams/` (every file) | CC0-1.0 | Procedurally generated by the OpenPlush project with `research/fixtures_gen/` |

To regenerate the generated files: `cd research/fixtures_gen && python3 generate.py`. The output is byte-for-byte reproducible, and `python3 -m unittest -v` in the same directory checks the committed files against it.

A contributed model gets its own row: path, license (CC0-1.0, or CC-BY-4.0 with the attribution text the license requires), and where it came from.
