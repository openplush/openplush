# Code of Conduct

OpenPlush adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space: issues, pull requests, discussions, and review comments, and to anyone representing the project elsewhere.

## In short

- Be kind and assume good faith. Many contributors here are makers and artists first, not programmers; a fixture or a sewing correction is as valuable as code.
- Criticise work, not people. Review comments point at a line, a test, or a claim, never at the person.
- No harassment, insults, sexualised content, or publishing anyone's private information.

## Reporting

Report a problem privately to the maintainers listed in [GOVERNANCE.md](GOVERNANCE.md). Reports are handled confidentially, and a maintainer will not act on a report about themselves. While the project has a single maintainer, report a problem with that maintainer to GitHub through [Report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam), which reaches GitHub's staff, not the project.

> **Maintainer action needed:** add a private reporting address here (a project email or form). Until then, contact a maintainer through their GitHub profile and ask for a private channel.

## Enforcement

The maintainers apply the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, or permanent ban, depending on the impact and whether it repeats.
