# OpenPlush documentation

Organised by [Diátaxis](https://diataxis.fr): four kinds of documentation, because a reader learning, doing, looking something up, and trying to understand need different pages.

| Section | For | Example |
|---|---|---|
| [tutorials/](tutorials/) | Learning by doing, start to finish | "Your first pattern from a capsule model" |
| [how-to/](how-to/) | A specific goal, for someone who knows the basics | [Size and open a pull request](how-to/pull-requests.md) |
| [reference/](reference/) | Facts to look up | CLI flags, warning codes, file format |
| [explanation/](explanation/) | Why things are the way they are | Why seam lengths are pinned exactly (D-013) |
| [adr/](adr/) | Architecture decision records | New dependency categories, principle changes |

Specs and plans live in [`specs/`](https://github.com/openplush/openplush/tree/main/specs/), not here: they say what will be built and why. These pages describe what exists.
