# Spike S7: boundary-pinned flattening (D-013), synthetic prototype

**Status (2026-10-14): preliminary.** This is a reference prototype run on a **synthetic** corpus. T007 asks for results "on every fixture", and `fixtures/` does not exist yet, so T007 stays open. Running `run.py` on real charts is the remaining step.

Non-shipping research code (plan.md: `research/` holds reference implementations, not product code). It answers the structural questions now so the Rust flattener (T079 boundary, T080 interior, T082 fallback) is designed around the right failure mode.

## The question

D-013 pins every chart's boundary edges to their 3D lengths, so the two sides of a seam always match, and puts all distortion in the interior. Research R3 lists two risks:

1. The prescribed lengths may not **close** into a flat outline.
2. The map may not be **injective** (some triangle folds over, det J ≤ 0), where free-boundary SLIM had a local guarantee.

## Method

| Step | What | Why |
|---|---|---|
| Boundary curvature | BFF (Sawhney & Crane 2017) with boundary scale factor u = 0: solve A_II u_I = −K_I, then κ̃ = κ + (A u)_B | u = 0 keeps every boundary length at its 3D value |
| Closure | Keep lengths; least-squares change to the turning angles subject to closure (SLSQP, then Gauss-Newton polish to 1e-14) | BFF closes by changing lengths, which would break parity |
| Outline check | Pairwise segment intersection | A self-crossing outline can't be cut |
| Interior start | Harmonic fill with the boundary fixed: cotan weights, then uniform (Tutte) weights | The two cheap linear starts the Rust code would try first |
| Interior solve | L-BFGS on the symmetric Dirichlet energy (SLIM's), boundary fixed, step capped at the first triangle flip (Smith & Schaefer 2015) | Cannot create a flip, but cannot repair one either |
| Baseline | Free boundary: Tutte onto a circle, then the same energy with every vertex free | How much distortion pinning costs, and how far boundary lengths drift without it |

Oracle tests (`test_s7.py`, 13 tests): Euler characteristic, Gauss–Bonnet for the 3D chart and for the flattened boundary, finite-difference gradient, exact closure with exact lengths, a flat disk that must map to itself (SD = 4 exactly), and a bent plane (developable) that must flatten almost isometrically.

Run it: `pip install -r requirements.txt`, then `python3 -m unittest -v` and `python3 run.py` (about 25 s).

## Results

Full table in [`results.md`](./results.md), generated by `run.py`. Read the columns as:
- **SD mean**: 4.0 means isometric (no distortion); higher is worse.
- **Stretch / compress**: the largest and smallest singular values. Compression 0.63 means the fabric there must gather into 63% of its 3D extent.
- **Reflex**: outline corners that turn inward, which shows the non-convex cases really are non-convex.

### Corpus (14 charts: oracles, caps, lobed and asymmetric outlines, saddle, gores, ear, bump)

- **Closure never failed.** The BFF outline's natural closure gap was at most **0.39%** of the perimeter. Closing it with lengths held exact needed at most **0.04°** of turning-angle change at any corner. Every outline was simple.
- **Injectivity never failed.** The cotan start had **zero** folds on all 14, including outlines with 14–40 reflex corners. The optimizer then kept them at zero.
- **The cost is interior distortion, and it grows fast with curvature:**

  | Chart | Pinned SD | Pinned min compress | Free SD | Free boundary-length drift (max edge) |
  |---|---|---|---|---|
  | cap-45 | 4.06 | 0.89 | 4.01 | 8.3% |
  | cap-90 (hemisphere) | 5.20 | 0.63 | 4.14 | 42% |
  | ellipsoid-cap-90 | 8.12 | 0.40 | 4.60 | 83% |
  | ear | 10.1 | 0.29 | 4.82 | 310% |
  | gore-90 (¼ of a ball) | 4.13 | 0.84 | 4.02 | 16% |

### Stress (5 deliberately extreme charts)

- **3 of 5 had no injective start**: lobed-cap-150, asym-cap-160, star-cap-120. Both linear starts folded triangles: cotan 1–16, uniform 92–201. Closure still worked (≤ 0.35° change, outline simple).
- **Refining the mesh makes it worse, not better:**

  | Chart | 384 tris (cotan / uniform folds) | 1536 | 3456 |
  |---|---|---|---|
  | lobed-cap-150 | 0 / 33 | 1 / 201 | 6 / 506 |
  | asym-cap-160 | 0 / 23 | 4 / 155 | 8 / 383 |
  | star-cap-120 | 4 / 7 | 16 / 92 | 18 / 263 |

- **bump-h1.2**: cotan folded but uniform didn't, so trying both starts is worth it.

## Findings

1. **Closure is not the failure mode** [likely; synthetic]. Pinning only lengths leaves every turning angle free, and a polygon with fixed side lengths closes unless one side exceeds the sum of the others. The fix needed was tiny everywhere, even on stress charts. R3's "fails to close" risk can be downgraded. The closure step still belongs in T079, as a least-squares angle correction rather than BFF's length correction.
2. **Injectivity is the real risk, and it's about shape, not resolution** [likely]. Cheap linear starts fail on strongly curved charts with deeply lobed outlines, and they fail *more* at higher resolution, so the Rust proxy (~30k triangles) will see more folds than this prototype, not fewer. These are charts no sensible seam layout should produce, but users will draw them.
3. **A fold is not proof that no injective map exists** [solid]. The prototype tried only two linear starts. Untangling methods (e.g. Garanzha et al. 2021, "Foldover-free maps in 50 lines of code"; Shen et al. 2019, progressive embedding) can often find an injective map with a fixed boundary. Whether they find one on these charts is not tested here.
4. **Pinned distortion is the dart signal** [likely]. On a hemisphere, the free solve hides distortion by stretching the boundary 42%. The pinned solve keeps the boundary exact and compresses the interior to 0.63. A plush maker would never cut a hemisphere as one piece; they'd use gores (gore-90: compression 0.84). The pinned interior's compression is exactly the FR-021 heatmap and FR-022 dart-suggestion input. This supports D-013's design: distortion goes where the sewist can see it and act on it.
5. **The free baseline is not Option B** [solid]. It is unweighted, so its boundary drift (8–490%) is an upper bound, not what a heavy-boundary-weight solve would produce. It shows parity cannot be left to a free solve. It doesn't measure how small Option B's residual could get, and R3 already rejected Option B on contract grounds.

## Recommendations for T079–T082

- **T079 (boundary)**: BFF curvature with u_B = 0, then least-squares *angle* closure. Never adjust lengths. Return a typed error if closure fails or the outline self-intersects. Neither happened here, but both are invariants.
- **T080 (interior)**: a start ladder: cotan, then uniform, then an untangling pass. Only accept a start with zero folds, because the flip-capped line search can't repair one.
- **T082 (fallback)**: when the ladder runs out, return the typed error with a dart or extra-seam proposal, as D-013 says. Never relax parity. The proposal can target the region with the folded triangles or the strongest compression.
- **Add a spike** (or extend S7 when fixtures land): does an untangling start rescue the three stress charts? That decides whether T080 needs the third rung.

## Limits

- **Synthetic surfaces only.** Real models have sharp features, anisotropic triangles, and seam layouts drawn by people. The fixture run is what closes T007.
- Symmetric Dirichlet is a geometric proxy, not a fabric model. "Compression 0.63" means "needs a dart", not a fabric strain measurement.
- Fold counts are for these two linear starts at these resolutions. The prototype makes no claim about the best possible start.
- 384–3456 triangles, not the ~30k proxy. Finding 2 says the larger mesh is the harder case.
