# settle: an ADR's status is a decision, and an ADR's body is a record, so neither
# is edited to get the check green. One line per finding: <ADR> <other ADR> <kind>
# <reason>, where the first ADR is the one to fix and kind is status or backlink,
# exactly as the check prints the key. A line whose finding is gone fails as stale.
#
# Example:
# NNNN MMMM backlink NNNN predates the note practice; the maintainer decides whether to annotate it
